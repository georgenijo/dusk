Connection & privacy

Jev receives structural signals such as colors, sizes, class names and image statistics, rather than page text or image pixels. Requests use the provider you select.

Dusk skips automatic Jev requests on private pages and pages using native dark mode, pages that are already dark, and sites you turn off.

Save settings first, then test the saved connection. A test sends a small synthetic image description, not the current page. Request attempts are not a measure of billed tokens.
